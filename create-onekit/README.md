# create-onekit

Official Vite-style project creator for OneKit JS.

## Usage

```bash
npm create onekit@latest my-app
cd my-app
npm install
npm run dev
```

You can also use the explicit executable form:

```bash
npx create-onekit my-app --template ts
npx create-onekit my-app --javascript
```

The creator generates a Vite-powered TypeScript starter by default. Use `--template js` or `--javascript` for a JavaScript starter.

## Requirements

Node.js 18 or newer is required. The generated project uses OneKit JS and Vite; dependencies are installed in the generated project with `npm install`.
